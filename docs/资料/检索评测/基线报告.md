## 五、这份基线怎么用

- 后续任何改动（口语词典扩展、向量召回、RRF 融合）都用**同一份评测集**复测，对比 Recall@10 / MRR / 失败用例数
- 失败用例列表就是改进清单：优先解决被漏掉次数最多的那几条法条
- 面试可讲的完整链条：先建评测集 → 量出基线 → 定位失败原因 → 改进 → 复测对比
