# 「言权」参赛冲刺清单

> 目标：2026 微信小程序开发者计划参赛交付。代码已完成并验证，剩余工作是**上线流程 + 参赛材料**。

---

## 一、上线流程（最耗时，立即启动）

| # | 事项 | 耗时 | 说明 |
|---|------|------|------|
| 1 | 购买域名 + 云服务器 | 1 天 | 阿里云/腾讯云轻量 2C2G；域名选 .cn 或 .com，约 50-100 元/月 |
| 2 | ICP 备案 | **1-3 周** | 个人备案即可；服务器和域名同一家云厂商最快 |
| 3 | 部署后端（Docker） | 0.5 天 | 按 docs/DEPLOY.md，一条命令起服务 |
| 4 | 配置 HTTPS + Nginx | 0.5 天 | 免费证书（Let's Encrypt / 云厂商免费证书） |
| 5 | 小程序后台配置 | 0.5 天 | 合法域名（request/uploadFile）、服务类目、隐私保护指引 |
| 6 | 修改 API 地址并构建 | 10 分钟 | `src/services/api.ts` 的 BASE_URL 改为你的 HTTPS 域名，`npm run build:weapp` |
| 7 | 上传代码 + 提交审核 | 2-7 天 | miniapp/upload.js 或开发者工具上传；审核注意类目与隐私 |
| 8 | 发布上线 | — | 审核通过后发布，正式二维码可用 |

> 关键提醒：**备案是长周期，今天就去申请**。先买服务器域名提交备案，其他步骤可以并行做。

## 四、二维码说明（别搞混）

1. **预览二维码**：微信开发者工具点「预览」→ 手机微信扫码，7 天有效——**报名/演示用它即可**；
2. **体验版二维码**：上传代码后在小程序后台设为体验版，长期有效；
3. **正式版二维码**：审核发布后生成，即用户搜索到的版本。

比赛提交一般要求"可体验"，预览码或体验版都行；正式上线码最有说服力。

## 五、风险与应对

- **类目/审核风险**：生成法律文书类内容，审核可能要求说明"不构成法律意见"（页面已有免责声明）；类目选"工具-效率"或"生活服务"，被驳回就按审核意见修改后重提。
- **备案时间不够**：若比赛截止早于备案完成，可先用"预览二维码 + 演示视频"提交（很多比赛允许），说明"上线流程进行中"。
- **隐私合规**：隐私保护指引已内置，上传图片/录音需在隐私声明中注明用途（文档已覆盖）。
